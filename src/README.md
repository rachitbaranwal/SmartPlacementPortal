# 🎓 Smart Placement Portal

A web-based Campus Placement Management System developed using **Spring Boot**, **Spring MVC**, **JSP**, **Hibernate**, and **MySQL**. The application helps students explore placement drives, apply for jobs, and enables administrators to manage placement activities through a centralized portal.

---

## 🚀 Features

### Student Module
- Student Registration
- Secure Login (BCrypt Password Encryption)
- Student Dashboard
- View Available Placement Drives
- Apply for Placement Drives
- View Applied Drives

### Admin Module
- Admin Dashboard
- Create Placement Drives
- Update Placement Drives
- Delete Placement Drives
- View All Student Applications
- Manage Placement Activities

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/rachitbaranwal/SmartPlacementPortal.git
```

### Open Project

Open the project using IntelliJ IDEA or Eclipse.

### Configure Database

Create a MySQL database.

Example:

```sql
CREATE DATABASE placement_portal;
```

Update your `application.properties` file with your MySQL username and password.

### Run the Project

Run

```
PlacementportalApplication.java
```

Open your browser:

```
http://localhost:8080
```
